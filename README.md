# 🎮 GamersConnect

A full-stack social platform for gamers to **discover games, track activity, and connect with the gaming community**.

---

## 🚀 Overview

GamersConnect brings together **game discovery** and **social interaction** into a single platform. Users can explore trending games, manage their gaming activity, and engage with other gamers through posts, groups, and real-time interactions.

---

## ✨ Features

### 🎮 Game Discovery

* Browse **trending** and **most anticipated** games
* Detailed game pages with:

  * Trailers & screenshots
  * Genres, platforms, release date
  * Ratings and metadata
* Powered by **IGDB API**

### ⭐ Personal Game Management

* Add games to **wishlist (playlist)**
* Create **custom collections**
* Track **owned games** with status:

  * Currently Playing
  * Completed
  * Not Started

### 🌐 Community

* Create and explore **posts**
* Like, comment, bookmark, and share
* Tag games in posts
* Trending hashtags and top gamers

### 👥 Groups

* Public & Private groups
* Invite users and manage roles (Admin/Member)
* Share posts within groups

### 💬 Real-time Interaction

* Chat functionality using **Socket.IO**

### 👤 User Profile

* Bio, social links, and profile customization
* Gaming stats and insights
* Achievements and XP system

---

## 🛠️ Tech Stack

**Frontend:**

* React / Next.js
* TypeScript
* Tailwind CSS

**Backend:**

* Prisma ORM
* PostgreSQL

**Other:**

* IGDB API (game data)
